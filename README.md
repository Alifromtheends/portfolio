# Freelance Launch Kit

Built for you in the last 10 minutes. Everything you need to start landing paid work.

## What's Inside

| File | Purpose |
|------|---------|
| `index.html` | Your portfolio & service page. Single file. Deploy anywhere. |
| `service-listings.md` | Copy-paste ready gigs for Upwork, Fiverr, Contra |
| `outreach-kit.md` | Cold emails, LinkedIn bio, Twitter thread, follow-ups |
| `deploy.sh` | One-command deployment guide (GitHub Pages, Netlify, Cloudflare) |
| `tools/proposal_generator.py` | Generate professional proposals & contracts in 60 seconds |

## Deploy in 2 Minutes

```bash
cd ~/freelance-launch
bash deploy.sh
```

Or manually:
1. Replace `your-email@example.com` in `index.html`
2. Update social links in `index.html`
3. Drag & drop the folder to [Netlify Drop](https://app.netlify.com/drop)
4. Done. Live URL in 30 seconds.

## Generate Your First Proposal

```bash
cd ~/freelance-launch/tools
python3 proposal_generator.py
```
